# Goal
The pilots start from a plugin with no leftovers, and its docs and diagrams can't drift from what it enforces. Removal happens in each milestone as replacements land. This milestone is the sweep and its checks ([0013](../decisions/0013-a-deterministic-ai-dlc.md)).

# Bolts
## B191 Diagrams generated from the rules
The diagrams in `overview.md`, `grid.md`, `state.md`, `intent-states.md` and the README are drawn by hand.
- AC-1 Generated blocks are rewritten by `aidlc docs`, and a golden test fails on any difference (`DOC-DIAGRAM`). They cover:
  - the canonical model;
  - the workflow with its pathways;
  - intent and increment states;
  - the kind matrix and the layers inside a domain;
  - the bundle's doc types and their relations;
  - the naming grammar;
  - the gate's checks in order.
- AC-2 The hand-drawn diagrams they replace are deleted.
## B192 Every code documented once
- AC-1 Every check code in `cli.json` is documented in exactly one design doc, and every code a doc names exists (`DOC-CODE`).
## B193 The old words are gone
- AC-1 `TERM-SYNONYM` runs on this repo. No retired word appears in its old sense in `plugin/`, `docs/` or `tests/`: unit for a work item, slice for a delivery step, bundle, component. The skill and agent prompts stay within 3 KB each.
## B194 Lessons, not reports
- AC-1 `docs/pilot/` becomes one `lessons.md`, each lesson naming the rule or check that now holds it. The 17 reports are deleted; git keeps them.
- AC-2 `later.md` holds only ideas still open.
## B195 No dead code
- AC-1 The hygiene test fails on an unreferenced export, a `cli.json` message no code reads, or a legacy alias past its expiry.
## B196 The README matches a fresh init
- AC-1 The README is rebuilt around the generated diagrams.
