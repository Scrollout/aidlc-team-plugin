# Platform and robustness
- Windows support: 57 tests fail on Windows, which CI reports but does not yet require.
- GitHub list endpoints sometimes return an empty list: `sync` treats an empty list as suspect (compare counts, retry with backoff) before any create.
- Tests clean up their temp dirs.
- Builder worktrees under `.claude/worktrees/` sit inside the repo, so a project's tree-walking tests see them: `init` adds them to the project's ignore lists, or the docs say so.

# Hooks and steering
- The guard's redirect and write detection is too broad: a `.github` script run with its output redirected is blocked.
- `next` blocks on an approval held for the owner, hiding independent unit work: offer that work beside the held approval.
- The lead cannot see whether the owner answered a permission prompt: the guard records answered owner prompts.
- Steer keeps pushing a stopped report after a new builder launched, and a step parked for the owner: a launch newer than the report wins, and a parked step stops the steering.
- `next` asks to re-approve a unit but not for a new decision the unit cites (prompt evals).
- Steer blocks a stop the owner asked for in the prompt (prompt evals).
- Owner run-mode instructions (unattended, where to report) live only in the conversation and are lost on `/clear`: persist them in the local profile.
- `MODEL-MISMATCH` names the card as the source when the model comes from `models.review`; the card prints the reviewer model too.

# Units and gate
- A restarted builder starts from the stale unit-branch tip: `start` merges the card's base into an existing unit branch.
- Plan lint checks that a non-quick unit's scope can hold a test at each AC's level, and that its test files sit in the level's paths.
- Plan lint cannot see an AC that needs another unit merged first.
- A bare root-file scope (`Makefile`) overlaps `**` globs: the message suggests the leading `/`.
- The gate, or the reviewer brief, runs the lane's full level `run`, not only the unit's own tests.
- `next` checks the AC tags before it offers a merge.
- A quick unit is offered for merge although its own AC fails: run the unit's AC tests before the offer.
- Findings a spec change answers are marked answered, or the re-review runs directly.
- A fix unit on a full-lane path is allowed with an owner approval instead of an intent.
- Should a criteria change be excluded from delegated re-approval? Owner question.
- `upgrade` refuses a dirty plugin tree or copies from a release tag.
- `init` suggests the project's lint target as a module check.
- The docs hook stamps `generated.at`, so no stamp is written in local time marked `Z`.
- `aidlc check <dir>` on a folder below the bundle root resolves bundle-root links against the wrong root.
- Regenerated indexes drop "Load when" hints, and new subfolders get no description line.
