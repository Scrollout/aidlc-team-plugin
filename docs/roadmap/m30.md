# Goal
Every concept the plugin uses has one word at one scale, each word one meaning, and the docs, messages and templates use those words ([Canonical model](../design/canonical-model.md)).

# Bolts
## B254 A complete canonical model
- AC-1 The vocabulary defines every concept the shipped text and the design docs use: the module kinds, the architecture model, the stack pack, the naming registry and the profile; the domain's aggregate, domain model, data node, contract, events, commands, queries, routes and handlers; the test level, acceptance criterion, proof-revert, mutation and scope; the request, requirement, persona, fact, decision, pathway, walking skeleton, method version and the release steps; and the docs bundle, merge gate, review, verdict, focus, agents, worktree, trailer, base, board, retro, stamp and AI model.
- AC-2 A word with several senses is split into one word per sense, and the words to avoid send the bare word, in each sense, to the one it means.
- AC-3 Each scale's words are a page drawn from `cli.json` beside the canonical model, each under its size cap, and a test keeps them in step.
## B255 One sweep of the words
- AC-1 The messages, fixes, templates, personas, skill, agents and design docs use each word in its canonical sense; a word to avoid in its avoided sense is reported by the words test, as the retired senses are.
## B256 The docs said once
- AC-1 Docs that repeat each other are merged into one, the others linking to it: the slice docs, the gate and verification docs, and any pair the audit finds; every design doc stays under its size cap, the generated gate codes split by group.
## B257 Old forms retired
- AC-1 The v1 aliases (`units/`, `U-<n>`) and the method versions no approved intent of a supported project uses are retired, with `upgrade` moving what a project still holds; the core and the extensions keep their line budgets.
## B258 The plugin's own code by its method
- AC-1 The CLI's own code is checked against the layering and slice rules it holds projects to, and what does not follow them is moved or recorded in a decision.
