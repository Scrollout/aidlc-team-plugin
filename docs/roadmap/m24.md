# Goal
A proven system's vertical and horizontal shape becomes a model the plugin applies to any similar project, the owner approving every decision it seeds ([Models](../design/models.md), [0020](../decisions/0020-architecture-models-are-data.md)).

# Bolts
## B228 The model format
- AC-1 A model folder (`model.json`, `knowledge/`, `decisions/`) loads from `plugin/cli/models/` and `.aidlc/models/`, the local one winning; `aidlc check` reports a model that breaks the format.
## B229 The modelling pathway
- AC-1 A `model` pathway intent needs its `research:` digests and a current Model doc (`aidlc models doc <name>`, generated from `model.json` with its digest), else `PATHWAY-SKIP`; the owner approves the Model doc.
- AC-2 Each layer, domain and rule of a project model cites a source of those digests, else `MODEL-SOURCE`.
## B230 Rule types
- AC-1 A project chooses its model in the profile (`model.name`); only the rules that model lists run, with the model's parameters and the profile's project names.
- AC-2 Stage order (`PIPELINE-ORDER`), slice contract (`PROVIDER-CONTRACT`), long-running operations (`LONG-RUNNING`), idempotency (`IDEMPOTENCY-AC`), data (`DATA-PARTITION`) and events (`EVENT-COVERAGE`) each report what breaks their rule.
## B231 Applying a model
- AC-1 Greenfield: intake lists the models whose fit words the request holds; `aidlc models apply <name>` records the choice, writes the system doc when there is none, copies the model's decisions as proposals once, and prints increments along its layers.
- AC-2 Brownfield: `aidlc models gaps` matches the modules (`layer`) to the model's items and kinds, and prints the missing ones as increments.
## B232 The control-plane model
- AC-1 The control-plane model ships under `plugin/cli/models/control-plane/`: its layers, domains, slice, rules, starter decisions and knowledge, in generic names; a scan finds no vendor name in it.
- AC-2 Its `contract` carries the resource hierarchy of decision 0014, which the contracts check applies only where a project chose the model ([0021](../decisions/0021-the-control-planes-api-conventions-belong-to-its.md)).
## B233 Reference slices
- AC-1 The Go pack carries the control-plane model's reference slices, tested; a second, minimal model applies with no change to the core.
## B234 The architect's model knowledge
- AC-1 The architect persona knows how to read a reference horizontally and vertically and how to write its rules as data, within its budget.
