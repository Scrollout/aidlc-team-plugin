## U40 Generated files in a scope
From the [M4 pilot 3](../pilot/m4-3-report.md): a scope named a generated file without its source, then an untracked copy instead of the tracked output.
- AC-1 The profile maps generated outputs to their sources: `generated: [{ "outputs": [<glob>], "sources": [<glob>] }]`.
- AC-2 Plan lint reports `PLAN-GENERATED` for a live unit whose scope overlaps an entry's outputs but none of its sources, or its sources but none of its outputs, naming the globs it lacks.
- AC-3 It also reports a scope entry naming a file that exists in the working tree but git does not track (untracked or ignored): a builder cannot commit it, as with the untracked copy in the pilot. A new file the unit creates does not exist yet and passes.
