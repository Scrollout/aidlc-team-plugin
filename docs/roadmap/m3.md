# Goal
A builder writes code the way the project does, and "test first" is checked rather than asked for. The rest of the grid moved to [M4](m4.md).

# Why
Measured against common advice on how agents write clean code, the plugin has deterministic gates, plan-first units and capped fix loops, and three gaps. Builders run without `CLAUDE.md` and their cards carry no `.aidlc/rules/`, so a project's conventions never reach them. Nothing checks that a builder writes a failing test first, so a test can pass without its change. No review looks for needless code, the most common way agent code goes wrong. Numeric style limits in prompts were rejected: AI models follow them loosely and they cost tokens on every run; projects get them from their own linters, which the gate already runs.

# Exit criteria
- A trial unit's card carries a project rule, and its builder and reviewer follow it.
- In a trial run, a tagged test that still passes with its unit's change reverted refuses the merge, and the owner sees why.
- CLI source within 3,400 lines (raised from 3,000 for M3); the other budgets in [Overview](../design/overview.md) unchanged.

## U27 Project rules on the card
- AC-1 The card carries each `.aidlc/rules/*.md` at the base commit, except a rule named after a review focus, which stays the reviewer's; rules come before the ACs and count toward the card's cap, and a card over the cap is refused naming the rules' share.
- AC-2 The research brief carries the same rules, so a project doc rule (a required line, a size) reaches the researcher.
- AC-3 A project with no rules folder gets the card and brief it gets today.

## U28 Proof-revert
- AC-1 On the trial merge, the gate reverts the unit's changes outside every level's test paths and runs each level whose paths hold one of the unit's tagged tests; a level that still passes refuses the merge as `GATE-PROOF`, naming the level.
- AC-2 A unit with no change outside its test paths, a quick-lane unit, or a level with no `run` is skipped and said so; the merge records the result in a `Proof:` trailer.
- AC-3 The builder's prompt says the gate checks red-first, and the card says which levels it will run.
