# Goal
One word means one thing at one scale, everywhere the plugin writes or checks. A project's bundle can be trusted as AI-DLC's context memory. Everything later builds on these words, so this milestone comes first ([0013](../decisions/0013-deterministic-ai-dlc.md)).

From this milestone on, roadmap items are bolts, numbered on from U148.

# Bolts
## B149 Room in the budget
The CLI was at 3,997 of its 4,000 lines, and the design docs carry 39 incident citations ("first migration", "second project") ([Overview](../design/overview.md)).
- AC-1 Each citation is listed with its fate. 31 are evidence for general rules and stay. 8 go with the slice rules increments replace (B152, B159).
- AC-2 With no room from deletion, the budget rises to 5,000 lines by [0016](../decisions/0016-cli-budget-5000.md), and v2's rules go into data wherever a check can read them.
## B150 The method doc holds the canonical model
"Vertical slice" meant three things across `slices.md`, `slice-architecture.md` and `map.mjs` ([Method](../design/method.md)).
- AC-1 [Canonical model](../design/canonical-model.md) states each scale's words, their AI-DLC terms (Intent, Unit = domain, Bolt) and sources, and says which rules are the plugin's own. `method.md` points to it.
- AC-2 The glossary in `overview.md` is a generated block from `cli.json`'s vocabulary, and a test fails when it differs.
## B151 Profile v2: system, kinds, surfaces
The profile could not tell a domain from a shared kit, or the core from an extension ([Profile](../design/profile.md)).
- AC-1 The profile takes `system` (core, extensions), `modules[].kind` (`domain`, `pipeline`, `foundation`, `adapter`, `runtime`, `extension`, `delivery`) and `modules[].surfaces` (`client`, `server`, `events`). A module without a kind is `PROFILE-KIND`, an error.
- AC-2 `upgrade` on a v1 project proposes a kind per module from its paths and names, and changes nothing.
## B152 Intents ship increments
The intent's `# Slices` mixed delivery steps with code slices ([Slices](../design/slices.md)).
- AC-1 An intent lists `# Increments` with ids `I-<n>.<k>`. Increment 1 is the walking skeleton, with a top-level AC.
- AC-2 `sliceRole`, the card's `Spec:` labels and `plan.sliceUnits` are removed with their tests, and the plan checks read increments.
## B153 Bolts
A "unit" was both AI-DLC's bounded context and the plugin's work item ([Unit card](../design/unit-card.md)).
- AC-1 A new intent's work items are `B-<n>` in `docs/bolts/`, allocated by `aidlc new bolt "<title>"`. Branches are `bolt/B-<n>` and test tags `B-<n>/AC-<k>`.
- AC-2 `U-<n>` and `units/` are read as legacy aliases only. A new doc under `units/` is refused.
## B154 Rules pinned per intent
Six plugin releases changed `resource-manager`'s rules in one day ([State](../design/state.md)).
- AC-1 Approving an intent records `method: <version>`, and checks on its bolts use that version's rules.
- AC-2 `upgrade` lists the rule changes it brings and applies them only to intents approved after it.
## B155 The map drawn by kind
The slices-and-layers page drew `toolchain` and `deploy` as vertical slices ([Codebase map](../design/codebase-map.md)).
- AC-1 The map draws domains as columns and horizontal kinds as bands, and leaves delivery modules out.
- AC-2 The slices page and `PLAN-ARCHDOC` are removed with their tests.
## B156 Bundle v2: layout and schemas
Hand-drawn architecture pages sat beside generated ones and disagreed ([OKF](../design/okf.md)).
- AC-1 `init` lays out the v2 folders (`constitution`, `method`, `system`, `domains`, `intents`, `bolts`, `requirements`, `decisions`, `platform`, `research`, `runbooks`, `naming`, `architecture`).
- AC-2 Each type's front-matter schema lives in `cli.json` and is checked (`DOC-SCHEMA`).
- AC-3 A hand edit to a generated doc, or a generated type in an authored folder, is refused (`DOC-GENERATED`).
## B157 Slugs and ids from the CLI
`resource-manager`'s files were cut mid-word: `…-typespec-wi.md`, `…-cluster-s-ns-.md` ([OKF validation](../design/okf-validation.md)).
- AC-1 A slug is generated from the title: lower case ASCII, hyphens, apostrophes dropped, at most 48 characters, cut at a word boundary, no trailing hyphen. Anything else is `DOC-SLUG`.
## B158 The bundle on the base is true
Indexes were stale on `resource-manager`'s main, and about 20 of this repo's design docs and five roadmaps are marked draft though built ([Gate](../design/gate.md)).
- AC-1 On the base, `HOUSE-INDEX-STALE`, `HOUSE-LINK` and `DOC-*` are errors in `check --ci` and at the gate.
- AC-2 `DOC-STATUS`: a design doc whose bolts are all built can't be draft. This repo's statuses are fixed by it.
## B159 The plugin's docs and templates speak the model
The plugin's own docs and templates carried the old words ([Grid](../design/grid.md)).
- AC-1 `increments.md`, `architecture-model.md` and `bolt-card.md` replace `slices.md`, `slice-architecture.md` and `unit-card.md`, which are deleted.
- AC-2 Templates `intent`, `bolt`, `system`, `domain`, `fact` and `module` replace `unit` and `architecture`. Constitution rules 9 and 11 use the canonical words.
