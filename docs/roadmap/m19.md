# Bolts
## B182 Bolts bind to one domain
- AC-1 A bolt binds one domain, or one horizontal module plus `neededBy: B-<v>` in the same increment (`BOLT-BIND`). It spans several domains only in increment 1 (`BOLT-SPAN`).
## B183 Parallel by ownership
Disjoint file globs let U-3, U-5 and U-6 collide and hold each other ([Parallel](../design/parallel.md)).
- AC-1 `next` starts bolts side by side only when their bindings differ and their scopes are disjoint. A shared file goes to a foundation bolt merged first.
## B184 A proof per AC
The revert proof accepted a compile failure ([Gate](../design/gate.md)).
- AC-1 `PROOF-AC`: with the implementation reverted, each top-level AC's tagged tests fail at run time.
- AC-2 A compile failure counts only through a recorded mutation per AC, as for back-fill tests.
## B185 Security findings need the owner
- AC-1 A security finding at any confidence blocks the merge until `aidlc dispose B-<n> F-<k> fixed|accepted "<reason>"` (owner only) (`REVIEW-SECURITY`).
## B186 The skeleton runs where it will run
- AC-1 Increment 1 holds a target-level AC and the delivery module (`INCR-SKELETON`).
- AC-2 An increment is done only after its smoke passes on the target (`INCR-DONE`). No later increment's bolt merges before increment 1 is done.
## B187 Delivered means proven
`state.mjs` counted a requirement delivered when any merged unit cited it ([State](../design/state.md)).
- AC-1 A generated traceability page per intent links requirement → AC → bolt → tagged test → gate run → release.
- AC-2 A requirement is delivered only when every one of its ACs passed on a released base (`REQ-DELIVERED`). The old count is removed.
## B188 Fix bolts fix one thing
- AC-1 A fix bolt has exactly one AC, a regression test that fails before the fix, and touches no decision (`FIX-SHAPE`). Fix units used as overflow are removed with their tests.
## B189 Escape hatches expire and count
- AC-1 Each of these is owner-only, carries `until`, and is counted by `status` and `retro`:
  - a fix bolt;
  - a waiver;
  - a boundary `except`;
  - `delegate`;
  - a security `accepted`;
  - a scope widening.
- AC-2 `retro` records per increment:
  - lead time from intent approval to passing smoke;
  - predictability (increments committed vs shipped);
  - merge refusals and conflicts by binding kind;
  - the owner's dwell time per approval.
## B190 The board shows the binding
- AC-1 A bolt's issue carries its binding (domain or module kind) in place of the removed `Spec` label, and `board.binding` maps it ([Board](../design/board.md)).
