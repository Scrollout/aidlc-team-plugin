# Goal
A vertical slice merges whole: every layer its use case needs, from the screen to the schema, planned where its story is written and checked where its code is merged ([Building a slice](../design/slice-method.md), [0026](../decisions/0026-a-slice-declares-the-layers-it-needs-and.md)).

# Bolts
## B250 Declared layers
- AC-1 Decision 0026 and the glossary define a slice's layers, own parts, shared layers, data, entry and integration.
- AC-2 Method 13: a `# Surface` line and a Unit of work's `Slices` line carry the slice's layers, data, entry, mode, events and calls; `UNIT-WORK` and `DOC-SCHEMA` report a layer the pack does not list, or none, a data node its domain neither owns nor shares, an entry `entries` does not define, an event in no domain's `events` surface and a call to no client or adapter.
- AC-3 A model's slice carries `layers`, `data`, `entry`, `mode`, `emits`, `consumes` and `calls`, and the model its `entries` with what each adds to its slices; `MODEL-FORMAT` checks them, `models apply` writes them into `# Surface`, `models gaps` lists a missing slice or layer, and intake lists each fitting model's slices with their layers and hand-offs.
- AC-4 The intent and domain templates, the product analyst and the architect carry the layers; the example control-plane model declares its entries with what each adds, and each slice's layers, data, entry and integrations.
## B251 Packs and scaffold
- AC-1 Each pack lists `sliceLayers`, each with the path of a slice's part, `ui` where the stack has one; the names come from the registry.
- AC-2 `scaffold slice` writes a file and a test for each declared own part and changes nothing that exists; each pack's reference slice declares its layers and passes every slice check.
## B252 Card and gate
- AC-1 `PLAN-SLICE` reports a bolt whose scope misses a declared layer's path.
- AC-2 The card lists each slice's layers as ordered test-first steps; the builder, the reviewer and the skill follow them.
- AC-3 `SLICE-DELIVER` refuses a bolt whose diff leaves a declared layer unchanged, naming the layer; the board lists each slice's layers, data and entry on its bolt.
- AC-4 `SLICE-DATA` refuses a data edge from a slice's code to a node it does not declare; `SLICE-ROUTE` refuses a slice whose route is wired outside the runtime of its entry; `SLICE-INTEGRATE` refuses an import of another domain's client, an adapter or an event type the slice does not declare, and a declared integration its code does not reach.
## B253 Proof and reports
- AC-1 `SLICE-TEST` requires a test at a level marked `entry` that names the slice's route, and one at a level marked `integration` for each declared event and call; a consumer's test names the publisher, and an `async` slice's test follows the status to a terminal state.
- AC-2 `INCR-SKELETON` requires increment 1's first slice to declare every layer the system's pack has.
- AC-3 `status`, `next`, the codebase map and the trace show the hand-offs between slices across domains, and each slice as planned, partial or done, layer by layer; the retro counts refusals by layer.
