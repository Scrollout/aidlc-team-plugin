## U52 Level runs at init
- AC-1 `init --run <level>=<command>`, repeatable, writes `levels.<level>.run` into the profile; a level the profile does not know or a value without `=` exits 64.
- AC-2 Without `--run`, `init` writes no `run` and prints, for each command it detects from the `cli.json` map, the flag to offer the owner (`--run unit=npm test`); the skill asks the owner for each level's command before running `init`.
- AC-3 Plan lint reports `PLAN-RUN`, a warning, while no level in the profile has a `run`.

## U53 Constitution at init
- AC-1 `init` writes `<bundle>/constitution/principles.md` of type `Principles`, unless the file exists or the bundle is adopted; every code it names is one the CLI defines, and it has a section for the project's own rules.
- AC-2 After `init`, the bundle's indexes list the constitution and `aidlc check` passes; AGENTS.md points to the constitution and stays within its 60 lines.

## U54 Upgrade adds what is missing
- AC-1 `upgrade` adds each `.aidlc/templates/docs/` template the project lacks, and the constitution when the bundle holds no doc of type `Principles`, regenerating the indexes; it overwrites nothing and names each file it added.
