# Subdirectories

* [constitution](constitution/index.md) - The eleven rules every design choice in this plugin is checked against.
* [decisions](decisions/index.md) - Numbered decision records in MADR 4.0: context, options, the choice and why, its confirmation.
* [design](design/index.md) - One doc per concern of the plugin, from the grid, state and gate to intake, models and values as data, and the generated diagrams.
* [lessons](lessons/index.md) - What running the plugin taught, each lesson naming the rule or check that now holds it, and the ones still open.
* [roadmap](roadmap/index.md) - The milestone plans, M1 to M26, and the Later list; the newest one is the current plan.
