# aidlc-team-plugin docs

Load a folder index, then one doc. Do not load whole folders.

* [Constitution](constitution/) - the principles every design choice is checked against. Load before any design or review.
* [Design](design/) - one doc per concern of the plugin: grid, state, card, team, verification, steering, paths, profile, CLI, OKF. Load when designing, building or reviewing a part.
* [Decisions](decisions/) - numbered decision records with options and why. Load before changing anything a decision froze.
* [Roadmap](roadmap/) - one plan per milestone with its units. Load when planning or building.
* [Change log](log.md) - newest-first bundle history. Load to see what changed in the docs.
